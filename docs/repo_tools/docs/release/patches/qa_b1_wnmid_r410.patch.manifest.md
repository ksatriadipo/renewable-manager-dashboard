## Ambang T = 0,60 (rasio LitCount / kavling berjendela-terender, sumber Region15xPower.Lit)
Bukti (region_17, MID ukuran 1,266, A57): b1r1u `uidev_a57_0211` semua jendela menyala (rasio efektif 1,00) warm 0,76 %; b1r3u `uidev_a57_0529` X15ELEC 397 kavling, 209 berlistrik ⇒ rasio 0,526, warm 0,24 %. Garis lewat dua titik: warm ≈ 1,097·r − 0,337 ⇒ 0,25 % tercapai di r ≈ 0,535. T = 0,60 sengaja DI ATAS titik silang (prediksi 0,32 % di T, margin ≥ 28 %): di atas T kriteria normal bisa dicapai produk dan DITEGAKKAN (warm ≥ 0,25 %, gumpal ≤ 0,10 %); di bawah T kekurangan warm adalah akibat rumah tak berlistrik yang menurut keputusan user tidak boleh diberi cahaya palsu. Ambang 0,25 % TIDAK diturunkan. Dua titik = data terbatas; Auditor mengkalibrasi ulang bila ronde berikut memberi titik rasio lain (perubahan hanya oleh Auditor, tidak melonggarkan).
CONDITIONAL_PASS (MID saja) = rasio < T DAN cek jendela lulus DAN meanL 80–112 DAN putih ≤ 0,30 % DAN gumpal TERUKUR ≤ 0,10 % DAN objek > 0, satu-satunya kekurangan = warm < 0,25 %. Baris memuat warm mentah + rasio + ambang. Tidak pernah dihitung PASS (Verdict.Pass=false; JobVerdict CONDITIONAL_PASS ≠ PASS).
